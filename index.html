Test order cleanup

Removes internal test orders from Shopify and Zoho

Connect to GitHub

The cleanup runs on GitHub. Sign in with a GitHub access token so this page can start runs and change settings for you. Your token stays in this browser.

How to create a token
  1. On github.com, open your profile picture, then Settings, then Developer settings, then Personal access tokens.
  2. If the repository belongs to an organization (recommended): choose Fine-grained tokens, Generate new token. Set Resource owner to the organization, pick only this repository, and give these repository permissions: Actions read and write, Variables read and write, Contents read. Add Contents and Workflows read and write only if you will change the schedule.
  3. If the repository is in someone's personal account: choose Tokens (classic), Generate new token, and tick the repo and workflow scopes.
  4. You also need to be a collaborator on the repository with at least Write access.

Automatic deletion is off

Scheduled runs only report what they would delete. Nothing is removed until you turn this on.
